Harness and model marks are vendored from @lobehub/icons-static-svg 1.101.0 (https://github.com/lobehub/lobe-icons), under the included MIT license. Color variants retain their upstream fills and gradients. openai-light.svg uses the upstream OpenAI path with a light fill for the dark interface.

pi-color.svg comes from the Pi coding harness's official https://pi.dev/logo-auto.svg, linked by https://github.com/badlogic/pi-mono. Only its viewBox is cropped to normalize the surrounding whitespace; its paths and three original colors are unchanged.

Gemini CLI uses its terminal mark; Gemini models use the Gemini sparkle. Claude Code uses its pixel mascot; Claude models use the Claude mark. Codex uses its color app mark; OpenAI models use the OpenAI mark. Unknown/custom endpoints retain a neutral globe rather than borrowing another vendor's identity.

Brand trademarks belong to their respective owners. These assets identify integrations; Flow is independent of those vendors. All assets are served locally; rendering them makes no third-party requests.

Grok uses the same upstream package Grok path, with a light fill for the dark interface.

fal-color.svg and bytedance-color.svg retain the original colored marks from the same pinned Lobe Icons package. fal identifies the execution provider; ByteDance identifies Seedance/Seedream models. flux-light.svg uses the upstream FLUX mark with a light fill for the dark interface.

ollama-light.svg uses the original Ollama llama mark from the same pinned Lobe Icons package, with a light fill for the dark interface. It identifies native Ollama HTTP execution, not Pi.
